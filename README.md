# Canadian Banking Data Science & Risk Analytics

## End-to-End Banking Analytics and Machine Learning Project

This project develops an end-to-end data science platform for analyzing the Canadian banking and credit environment using publicly available Bank of Canada data.

The project combines data engineering, exploratory data analysis, feature engineering, statistical analysis, machine learning, and executive-level banking risk analytics.

---

## Project Objective

The objective is to investigate relationships between:

- Canadian monetary policy
- Bank Rate
- Mortgage lending
- Personal lending
- Credit cards
- Lines of credit
- Business lending
- Credit growth
- Interest-rate volatility

The project also develops a machine-learning model to estimate the probability of credit-growth acceleration.

## Key Insights

The analysis investigates:

1. How monetary-policy changes relate to credit growth.
2. How mortgage, personal, and business lending behave differently.
3. How interest-rate volatility relates to banking stress.
4. Whether historical banking indicators can help predict credit-growth acceleration.
